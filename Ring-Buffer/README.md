# Ring-Buffer

Здесь реализован класс `RingBuffer` — кольцевой буфер фиксированного capacity для `int`, реализованный на массиве

Реализовано:
- `TryPush(int)` — добавить элемент в конец, `false` если буфер полон;
- `TryPop(int*)` — забрать элемент из начала, `false` если буфер пуст;
- `Size()`, `Empty()`

### Пример использования можно посмотреть в `main.cpp`.

Компиляция:
```
g++ -std=c++17 -Wall -Wextra -o ring_buffer main.cpp
```

Запуск:
```
.\ring_buffer
```
