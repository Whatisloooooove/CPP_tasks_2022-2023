# Factorization

Здесь реализована функция `Factorize(int n)`, которая возвращает вектор простых
множителей числа `n` (с повторениями), используя перебор делителей до
`sqrt(n)`.

Пример использования можно посмотреть в `main.cpp`.
Компиляция:
```
g++ -std=c++17 -Wall -Wextra -o factor main.cpp
```

Запуск:
```
.\factor
```
