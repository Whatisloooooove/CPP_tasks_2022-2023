# Matrix

Шаблонный класс `Matrix<N, M, T>` из `matrix.hpp` — матрица фиксированного
(compile-time) размера `N x M` над типом `T` (по умолчанию `int64_t`),
хранится как `std::vector<std::vector<T>>`.

Реализовано:
- конструкторы (нулевая матрица, из готового `vector<vector<T>>`, заполнение
  одним значением), копирование;
- `operator()` для доступа к элементам, `operator==`;
- арифметика: `+=`, `-=`, `*=` (на скаляр), а также свободные функции
  `operator+`, `operator-`, `operator*` (матрица на матрицу и матрица на
  скаляр, с проверкой размерностей через шаблонные параметры);
- `Transposed()` — транспонирование, `Trace()` — след матрицы (только для
  квадратных).
